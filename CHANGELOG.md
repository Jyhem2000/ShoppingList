# Journal des versions

Toutes les évolutions notables de ShoppingList. Format inspiré de [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/), versions [SemVer](https://semver.org/lang/fr/).
La section de la version courante alimente l'écran « Quoi de neuf » de l'app.

## [0.1.0] — 2026-11-08

Phase 1 : socle technique.

### Ajouté
- Application installable sur l'écran d'accueil (iPhone et Android), plein écran, fonctionnant hors ligne.
- Écran de premier lancement expliquant comment installer l'app selon le téléphone et le navigateur.
- Thème sombre au fond quasi noir, accents violet pâle et or, police Nunito, barre d'onglets Liste / Catalogue / Réglages.
- Bandeau de mise à jour quand une nouvelle version est disponible.
- Écran « À propos » : numéro de version, recherche de mise à jour, licences des bibliothèques utilisées.
- Réglages → Fonctionnalités : sons (tous ou un par un, avec écoute, mode silencieux respecté sur iPhone), vibrations, écran allumé pendant les courses ; grisées si le téléphone ne les permet pas.
